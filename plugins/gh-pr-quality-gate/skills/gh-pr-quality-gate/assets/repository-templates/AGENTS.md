# Repository Agent Instructions

Read `docs/repo_rule.md` before changing files, creating a branch, committing,
pushing, or reviewing a pull request. Then read the applicable product,
architecture, API, development, and testing documentation.

- Preserve unrelated changes and inspect `git status` before work.
- Associate every pull request with an issue.
- Run configured local checks before pushing.
- Update authoritative documentation when a public contract changes.
- Do not merge, force-push, close work items, or change Draft status without
  explicit authorization for that exact operation.
