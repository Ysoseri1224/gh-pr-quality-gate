# Support

Use GitHub Issues for reproducible bugs, platform compatibility problems, and
bounded feature requests. Include the extension version, operating system,
relevant non-secret configuration, exact command, and sanitized output.

Use GitHub Discussions for usage questions when available. Use private
vulnerability reporting for security issues. Never publish tokens, credentials,
private repository content, or organization-only policy in a public report.

This community project provides no guaranteed response time or service-level
agreement.
